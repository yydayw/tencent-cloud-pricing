## 常见问题

**云服务器一个月最低多少钱？**
活动秒杀机可以低到月均3元左右，比如38元/年的4核4G款；但限量、限流量，续费价也不固定。常规入门轻量机月均15元左右更现实。

**为什么年付比月付便宜那么多？**
年付和15个月付是厂商锁客的主要方式，折扣集中在这里；月付按原价计费，适合短期。长期项目选年付，短期测试选月付。

**月付的云服务器能备案吗？**
通常不行。腾讯云备案要求服务器租期在3个月以上，只买一个月无法满足。需要备案就直接买3个月或更长，具体以腾讯云备案页面的最新要求为准。

**轻量应用服务器和云服务器CVM选哪个？**
轻量适合个人站、测试环境、小程序后端，开箱即用；CVM适合需要自定义网络、负载均衡、多机集群的业务。配置需求简单时，轻量的性价比更高。

**活动机续费会涨价吗？**
首单价和续费价通常不是同一个数。下单前在页面确认续费金额，长期项目可以直接买15个月或更长的周期。
